<objective>
Generate a real `.icns` app icon from the existing vector eye artwork so the macOS `.app`'s Dock/Finder icon is the actual Orgtree icon instead of missing or a default. Implements PKG-02.

Purpose: electron-builder's `mac` target requires a `.icns` file (it cannot reuse the existing `.ico`); this closes that gap using the OS's own `iconutil` converter and the project's existing dependency-free PNG rasterizer, adding no new libraries.
Output: `apps/desktop/assets/orgtree-eye.icns`, committed like the existing `.ico` assets, plus test coverage.
</objective>
