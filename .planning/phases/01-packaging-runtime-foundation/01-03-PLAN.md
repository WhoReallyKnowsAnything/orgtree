  <name>Task 2: afterPack ad-hoc signing hook for bundled runtime binaries (PKG-01)</name>
  <files>tools/sign-runtime-macos.mjs</files>
  <behavior>
    - Given a fake appOutDir with a Contents/Resources/engine/runtime tree containing a few files, the hook calls codesign on every file under that tree.
    - The hook no-ops (returns without error) when electronPlatformName is not 'darwin'.
    - The hook no-ops when the runtime directory doesn't exist (e.g. a --dir build without extraResources staged yet).
    - A codesign failure on one file (e.g. a non-Mach-O .py/.json file) does not abort the walk — it's caught and skipped.
  </behavior>
  <action>Create tools/sign-runtime-macos.mjs exporting a default async `afterPack(context)` function, per electron-builder's documented afterPack hook contract (runs after files are packaged, before electron-builder's own code-signing phase). Return immediately if `context.electronPlatformName !== 'darwin'`. Resolve `runtimeDir` as `context.appOutDir` joined with `${context.packager.appInfo.productFilename}.app`, `Contents`, `Resources`, `engine`, `runtime`, and return immediately if it doesn't exist (fs.existsSync). Walk every file under `runtimeDir` recursively (a local generator function, mirroring the existing recursive-walk style already used in tools/runtime-layout.mjs's `walkFiles` — do not add a new dependency for directory walking) and run `execFileSync('codesign', ['--force', '--sign', '-', file])` on each regular file, wrapping each call in try/catch so a non-Mach-O file (a stray .py/.json/.txt) failing to sign doesn't abort the loop. Scoping this walk to exactly `Contents/Resources/engine/runtime`, and never walking outside it or accepting an externally-influenced path, is the mitigation for T-01-05 below. Do not use `codesign --deep` anywhere (Anti-Patterns to Avoid: `--deep` after electron-builder's own signing pass can re-sign nested items out of order) — this hook only touches the `extraResources` runtime tree electron-builder's own signer never reaches.</action>
  <verify>
    <automated>npm run package:mac:dir && codesign --verify --deep --strict release/mac*/Orgtree.app</automated>
  </verify>
  <done>tools/sign-runtime-macos.mjs exists and is wired via build.afterPack; a real --dir build ad-hoc-signs both the top-level .app (electron-builder's own pass) and every nested runtime binary (this hook's pass), and codesign --verify --deep --strict exits 0 on the bundle both before and after a launch.</done>
